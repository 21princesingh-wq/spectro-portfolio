## How to Run

1. **Download** all files into the same folder
2. **Open** `index.html` in any modern browser (Chrome, Firefox, Edge)
3. No server required — runs 100% offline

> ⚠️ Keep all 3 files (`index.html`, `style.css`, `script.js`) in the **same folder**.
> If they are separated, the styles and interactivity will not load.

## Features
- Fully routed single-page application (no page reloads)
- Animated spectrum bar (400–700nm gradient)
- SVG waveform and spectral chart
- Staggered card entrance animations
- Mobile responsive with hamburger menu
